geometor.archimedes.sphinx_ext
==============================

.. py:module:: geometor.archimedes.sphinx_ext

.. autoapi-nested-parse::

   Runtime Sphinx & photon-platform/publish integration for GEOMETOR Archimedes.

   Configures offline-safe local intersphinx inventories across the GEOMETOR canon
   (``euclid``, ``elements``, ``etc``, ``pappus``, ``pacioli``, ``wildberger``,
   ``proclus``, ``hilbert``, ``hoenen``) and drops unreachable remote-only targets
   so offline sandbox builds complete with zero warnings.
